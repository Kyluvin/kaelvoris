# Kaelvoris 用户手册

> 适用对象：使用桌面端 / 移动端 / CLI 的最终用户
> 关联文档：[deployment.md](../04-部署与运维/deployment.md)（安装与部署）、[admin-guide.md](../04-部署与运维/admin-guide.md)（服务端管理员）

## 1. 安装与启动

### 1.1 桌面端（Windows）

1. 下载安装包：`<服务器地址>:8900/download/kaelvoris-desktop.exe`（约 38.5MB 单文件，免安装；地址向管理员获取）。
2. 双击运行即可（建议放到独立目录，自升级备份会生成在同目录 `_backup\`）。
3. 首次启动进入设置，配置模型后即可使用。

### 1.2 移动端（Android）

1. 下载 APK：`<服务器地址>:8900/download/kaelvoris-shell.apk`（约 44KB WebView 壳；地址向管理员获取）。
2. 安装后打开即加载移动端 H5；也可直接浏览器访问 `<服务器地址>:8900/m/`。
3. 用统一账号登录（与桌面端同一套账号）。

### 1.3 CLI（开发者）

```powershell
# 单任务
kaelvoris -task "实现一个函数"

# 管道模式
echo "任务描述" | kaelvoris

# 全自动（YOLO）
kaelvoris -task "..." -y

# 指定端点与上下文窗口
kaelvoris -base-url https://api.deepseek.com -api-key sk-xxx -model deepseek-chat -context-window 128000
```

### 1.4 桌面端自升级

设置 → 版本页 → 「检查更新」→ 发现新版本自动提示（含新功能说明）→ 「一键升级」。升级自动备份旧版（保留 10 份），启动探活失败自动回滚。

## 2. 首次配置（桌面端）

打开设置抽屉（左下角齿轮）：

| 配置项 | 说明 |
|---|---|
| **模型**（必填） | BaseURL（OpenAI 兼容端点）+ API Key + 模型名。例如 DeepSeek：`https://api.deepseek.com` + `deepseek-chat` |
| 工作区 | Agent 工作的默认项目目录；每个会话可单独改 |
| 自动审批 | 开启后工具调用免人工确认（风险自担；新手建议关闭） |
| 危险操作自动确认 | 命中危险清单的命令免审放行（敏感文件写入红线不受影响） |
| 上下文窗口 | 填模型 token 上限（如 128000）启用长任务自动截断 |
| 生成图片/视频/语音 | 填 OpenAI 兼容端点后，聊天里可让 Agent 画图/生成视频/配音 |
| 成本单价 | 每百万 token 美元单价，填了会显示每轮成本估算 |

## 3. 日常使用

### 3.1 对话执行任务（核心用法）

1. 左栏选择或新建会话（每个会话绑定一个工作区）。
2. 底部输入框描述任务，回车发送；可拖入图片。
3. 中栏实时观看执行流：思考（可折叠）→ 工具调用卡 → 流式文本 → 结果。
4. 遇到审批卡（执行命令/写文件/追问）时点「批准」或输入自由文本回复。
5. 任务结束显示 ✅ 完成摘要；输入框可继续追问（同一会话多轮）。
6. 右栏「待办清单」实时显示任务分解进度（n/n）。

运行中可点「停止」随时中止；运行中再发消息会自动排队，本轮结束后续发。

### 3.2 模式切换

顶栏模式下拉切换（或让 Agent 用 `switch_mode` 自动切）：

| 模式 | 适用 |
|---|---|
| 🏗️ Architect | 方案设计、技术规划（只读） |
| 💻 Code | 写代码、改代码（默认） |
| ❓ Ask | 答疑、讲解（只读） |
| 🪲 Debug | 排查问题、定位根因 |
| 🪃 Orchestrator | 拆解大任务并委派子任务 |

### 3.3 发送框附加能力

- **远程节点选择器**：指定任务在哪台 PC 节点执行（多机组网时）。
- **员工选择器**：指定数字员工身份发消息（见 §3.8）。
- **图片附件**：发图给 Agent（截图分析、UI 对照）。

### 3.4 常用面板（左侧图标轨）

| 面板 | 用途 |
|---|---|
| 💬 对话 | 主界面（会话列表 + 聊天 + 待办） |
| 🌿 Git | 分支/暂存/diff/提交/推送/拉取/历史 + GitHub PR（列表/创建/合并/CI） |
| ⚡ 自主迭代 | AI 规划 → AI 审核 → 排期 → 并行开发（见 §4） |
| 🧩 技能库 | 内置/全局/项目三级技能管理与分类 |
| 🧵 流程编排 | 可视化流程画布 + 流程应用 + 单节点调试 |
| 👥 员工 | 数字员工档案与提案 |
| ⏰ 定时任务 | cron 任务增删改查、启停、立即执行 |
| 📄 文档 | workspace/doc 文件树 + 在线编辑 |
| 🔍 向量库 | 代码库语义索引与检索配置 |
| 🖥️ 远程节点 | 多机组网：查看在线节点、定向派发任务 |
| 🔄 版本 | 版本信息 / 检查更新 / 一键升级 |

### 3.5 会话管理

- 侧栏会话列表：重命名、删除、切换工作区、绑定 ACP agent / 数字员工。
- 运行中会话显示绿点；多开实例互不干扰。
- 会话清理面板：AI 分析低价值会话 → 生成分析文档 → 归档删除。

### 3.6 上下文 @ 提及

输入框支持 @ 引用：`@文件名` 快速带文件上下文、`@模式` 建议切换（具体以输入框自动补全为准）。

## 4. 自主迭代规划板（⚡）

让项目「自己开发自己」的规划执行闭环：

1. **生成规划**：右侧「AI 规划」栏可填引导意见（如「优先修 BUG」）→ 点「生成规划」→ AI 聚合项目结构/git 近况/经验卡产出提案列表。
2. **查看提案**：点卡片看详情（实现要点/审核意见/结果）。
3. **两种审核方式**：
   - 人工：勾选提案 → 选并行/依次（并行数 1~4）→ 点「执行」。
   - AI 审核：点「AI 审核」（可自定义审核提示词并保存为默认）→ 通过的自动进入开发，驳回的留痕。
4. **自动执行**：卡片进入「排期开发」→ 自动创建 `roadmap_<id>` 会话并行开发 → 完成/失败状态实时流转 → 可一键重试失败项。
5. **完全自主模式**：打开右侧开关（可配间隔/每日上限/并行数），系统自动「规划 → AI 审核 → 开发」循环；每日额度耗尽自动暂停，防失控。

> 注意：自动开发不自动提交 git，改动在 Git 面板审核后提交；多开实例请只在一个实例开启自主模式。

## 5. 定时任务与自进化

### 5.1 定时任务

面板或对话里说「每天 9:30 帮我跑 XX」皆可（Agent 内部用 cron_job 工具）：

- 表达式：5 段 cron（`30 9 * * *` = 每天 9:30）或 `@every 2h`、`@daily` 等描述符。
- 每条任务可设：工作区、模式、超时、失败重试（0~3 次）；连续失败自动熔断。
- 「立即执行」可手动触发一次。

### 5.2 自学习

- 每轮任务结束自动复盘（可在设置开/关 SelfReview）。
- 复盘沉淀的经验卡下次任务自动注入（`<self_evolution>` 段），越用越顺手。
- 定时自检（hourly review）可周期性沉淀经验卡。

### 5.3 会话总结

- 任务结束后自动生成「会话总结」：目标 / 状态（已完成 / 未完成 / 已停止）/ 产出 / 下一步，聊天流尾部以总结卡片展示。
- 会话列表带「总」角标表示已有总结；点开会话即可在末尾查看。
- 设置 → 会话总结开关（taskSummary.enabled）控制；关闭后不生成，历史总结保留。
- 总结由模型后台生成，失败时静默跳过，不影响任务收尾与聊天。

## 6. 知识增强能力

### 6.1 技能库

技能 = SKILL.md 指令包，Agent 经 `skill` 工具按需加载。三级来源：内置（builtin）/ 全局（`~/.kaelvoris/skills/`）/ 项目（`<workspace>/.kaelvoris/skills/`）。面板可新建、编辑、分类、启停；对话里直接说「用 XX 技能做 YY」。

### 6.2 向量知识库

设置 → 向量库：配置 embeddings 端点 → 选择目录 → 立即索引（或定时增量）。索引后 Agent 写码/答题前自动语义检索代码库（codebase_search）。

### 6.3 MCP 服务器

设置 → MCP：配置 stdio（本地命令）或 http/sse（远程端点）服务器；工具以 `mcp_<服务器>_<工具>` 名进入 Agent 工具集；支持认证头、工具白名单。

### 6.4 外部编码 Agent（ACP）

设置 → ACP：配置 Claude Code / Gemini CLI / Codex 等命令行 agent；会话可绑定其一，消息由外部 agent 执行、本端实时展示，审批与文件读取双向打通。

### 6.5 媒体生成

配置端点后，聊天里直接说「画一张 XX」「生成一段 XX 视频」「朗读这段话」；产物落 `~/.kaelvoris/images|media/`，聊天内直接预览/播放。

## 7. 多机协同（远程）

### 7.1 把 PC 变成节点

设置 → 远程：填服务端地址与节点令牌 → 连接。桌面端右上角出现远程状态。

### 7.2 指挥远程节点

- 桌面端「远程节点」面板：查看在线节点/模式，发送任务、续聊、审批、取消。
- 手机 H5 / APK：4 tab（任务/会话/节点/我的），发布任务、看流式、审批、续聊、切模式。
- 同机多开：第二个实例自动派生独立节点身份（名称加槽位号），可定向派发。

### 7.3 断线与恢复

节点断线 ≤150 秒重连，任务继续；服务端误标失败的任务可在移动端点「核实」按钮按 PC 本地真实状态校正；节点断线期间执行的任务历史在重连后自动补传。

## 8. 数字员工

员工面板创建员工（名称 + 角色提示词 + 头像）：

- 会话绑定员工后，其角色提示词接管 Agent 行为（如「严谨的后端工程师，只用 Go 标准库」）。
- 双工作区：任务仍在会话自己的工作区（用户项目目录）执行；员工专属工作空间（记忆/进化提案沉淀）保持可达，权限网关同时放行两区，其余路径一律拒绝。会话未设工作区时才以员工工作空间为工具目录。
- 发送框可选「以某员工身份」发消息，按员工视角归档任务。
- 员工可复制、停用、删除；提案列表查看员工产出的建议。

	## 9. IM 通道（飞书 / 企业微信 / 通用 IM）

	设置 → 消息渠道：配置飞书（WS 长连接，App ID/Secret）、企业微信（回调/WS）或通用 IM（任意 IM 平台可配）。

	- 群里 @机器人发任务 → 桌面端执行 → 结果回群里。
	- 审批卡用文本协议回复：`y` 同意 / `n` 拒绝 / 自由文本回答追问。
	- 通用 IM（平台无关，`API 根`必填，代码不写死任何平台地址）。三种接入：
		- 公共号模式：公共号菜单回调 URL 指向本机 `http://<host>:<端口>/im/callback`（默认端口 9881），用户消息经回调接收，回执经 `pubsendV2` 定向回传（PubToken 验签，需配置公共号 ID/密钥/企业 EID）。
		- 群机器人模式：仅向群内单向推送（完整 Webhook URL 或 Webhook Token），不支持接收用户消息；发送报文经出参模板渲染（`{{text}}` 为回复文本占位符，如 `{"msgtype":"text","text":{"content":"{{text}}"}}` 适配目标平台格式）。
		- 群消息接收模式：本机启动 HTTP 接收端点 `http://<本机IP>:<端口>/im/group/<hookID>`（默认端口 9881），每个 Hook ID 对应一个群组（逗号分隔可配多个，会话按 `im-group-<hookID>` 隔离）；推送格式经「入参字段映射」显式适配（目标字段=源路径，如 `text=Payload.Content`，点分嵌套、大小写不敏感，未配置字段回退宽松解析），全量原始报文写入日志，任务回复经群机器人 Webhook 推回群（建议同渠道一并配置 Webhook + 出参模板）。

## 10. 常见问题（FAQ）

| 问题 | 处理 |
|---|---|
| 任务运行中窗口闪退 | 已有 panic 防护不会再闪退；若异常终止看 `~/.kaelvoris/app.log` 尾部 |
| 流式卡住不动 | 引擎有看门狗自动重试（默认 3 次）；长时间无响应点「停止」重发 |
| 提示「是否继续执行」 | 达到 MaxRequests 限制（默认近似不限）；长任务可忽略，防失控场景可调低 |
| 会话列表打不开/某会话损坏 | 损坏文件已自动隔离为 `.corrupt`，删除即可，不影响其他会话 |
| 审批卡太多 | 开「自动审批」或按需开「危险操作自动确认」（新手建议保持人工） |
| 生图/生视频报错 | 检查设置里对应端点/模型/Key；未配置时工具会提示去设置页 |
| 升级后无法启动 | 自动回滚旧版；`update-failed.txt` 有说明；可手动从 `_backup\` 还原 |
| 远程任务状态不对 | 移动端任务页点「核实」小圆圈，按 PC 本地状态校正 |
| MCP 工具不出现 | 检查 mcp.json 配置与服务器连通性；看设置页 MCP 状态 |
| 多实例互相顶替 | 0.6.3+ 已按槽位派生身份；若仍顶替，升级客户端 |

## 11. 数据与隐私

- 全部数据在本地：`~/.kaelvoris/`（会话/配置/技能/经验卡/媒体产物）。
- 对话内容仅发送给你配置的 LLM 端点；远程模式下任务事件经你自己的服务端中转。
- APIKey 在服务端侧一律掩码存储与展示。
- 客户端凭据（desktop.json / localStorage）为明文本机存储，与 PC 本机安全同级假设；勿在共用机器保存敏感 Key。
